# goit-js-hw-07 — DOM & Events

## 📌 Project Description

This project contains a set of JavaScript tasks focused on working with the DOM (Document Object Model) and handling browser events.

The main goal is to practice selecting and manipulating DOM elements, handling user interactions, and dynamically creating content using JavaScript.

---

## 🚀 Technologies Used

* HTML5
* CSS3 (Flexbox)
* JavaScript (ES6+)
* DOM API
* Event handling

---

## 📂 Tasks Description

### Task 1 — Categories List

* Select all categories from the list.
* Count and display the number of categories.
* For each category, output the category title and the number of items it contains.

---

### Task 2 — Image Gallery

* Create a gallery based on an array of image objects.
* Dynamically generate `<li>` and `<img>` elements.
* Render all gallery items in a single DOM operation.
* Apply basic Flexbox styling for layout.

---

### Task 3 — Live Name Output

* Listen for the `input` event on a text field.
* Display the entered value inside a greeting message.
* Trim whitespace from the input value.
* Show "Anonymous" if the input is empty or contains only spaces.

---

### Task 4 — Login Form

* Handle form submission using the `submit` event.
* Prevent page reload on submit.
* Validate that all fields are filled using JavaScript.
* Show an alert if any field is empty.
* Collect form data into an object.
* Reset the form after successful submission.

---

### Task 5 — Color Switcher

* Change the background color of the `<body>` on button click.
* Generate a random hex color using a helper function.
* Display the current color value in the UI.

---

### Task 6 — Boxes Generator

* Create a collection of colored `<div>` elements based on user input.
* Validate input range (1–100).
* Apply random background colors to each box.
* Provide functionality to destroy all created boxes.

---

## 📦 Project Rules

* Do not modify the original HTML structure.
* All tasks must follow the technical requirements strictly.
* Code must be formatted using Prettier.
* No errors or warnings in the browser console.
